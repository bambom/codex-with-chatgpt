## 实施与验证节奏（2026-10-12 用户要求）

按功能批次连续实现多个任务，再统一编译、测试和集成验证，减少小步骤验证对推进速度的影响。

- 每批开始列出多个具体功能项、完成条件和受影响范围；完成这些实现后再进入统一验证，不把每个文件、接口或小改动都拆成测试轮次。

- 批末统一执行一次覆盖本批改动的编译、定向检查及必要的原生界面/持久化回归；不因合并验证而降低原有验收门槛。

- 进度按“本批已实现、待统一验证、验证结果、下一批任务”记录。未测试的实现明确标为待验证，通过后统一提交并更新证据。

早期 P0-A SQL 只属未部署设计稿，其中直接外键原 `design_record` 的方案已被替代。实际迁移需按复制服务的表/锁/约束重新确定；不改已应用迁移，不复制生产数据或 Cookie。

## 5. 原生编辑、标准发布与 GPT 接纳

普通编辑沿用原生保存；真实 ACK 只确认草稿已持久化。标准发布读取一个已确认 checkpoint 及持久语义，经 bridge/校验/重建后形成不可变标准修订与正式回执。发布失败保留草稿和旧发布版本；迟到回执不能清除后续编辑。

稳定 ID、UI 控件/实例/状态等元数据必须参与原事务、Undo、重开和复制。先验证原 codec 的扩展能力；不够时只扩展副本协议/模型或增加绑定原事务的原子元数据操作。内存 Map、DOM 属性不能作为持久语义来源。

GPT 候选按准确已发布基线和当前原生持久版本合并。标准 head 落后于原生草稿时，先投影当前 checkpoint；不能以旧 head 覆盖新编辑。合并结果重新校验并经原导入/codec/服务端重放验证；最终在同一设计锁和数据库事务下写实际原生变更、语义、依赖、标准修订、指针与成功回执。最终再次核对 native 和标准版本；变化时重算或返回冲突。

固定运行包的 worker 可使用隔离无界面浏览器和完整原壳，输出候选/映射/预览/报告，不能推进数据库 head 或驱动用户窗口。Node/Sharp 拼接可用于它已支持的标准范围，不自动等同完整原生 bridge。

同一幂等作用域/键仅对应同一指纹；数据库仲裁并发，未知结果先查询。原生 ACK 与标准正式回执分开，正式回执记录候选/最终摘要、合并基线、native checkpoint、bridge/规范版本与 validationId。对象存储与数据库不宣称全局原子，残留字节遵循引用/草稿保留规则。

插件工作区连接不等于平台授权。P1 确定真实配对/签发、范围、存储、续期/撤销，P3 验证；不复制浏览器 Cookie、不冒用管理员、不让模型指定 actor/owner。共享素材在设计锁和真实权限下冻结为设计长期可读的依赖。

## 6. 阶段顺序与验收

| 阶段 | 交付与通过门槛 |
| --- | --- |
| R0/B0 | 补齐全部原功能目录、完整产品来源/依赖/翻译状态、组件/CSS、通信/表、clone map 与原应用运行基线；本轮静态调研不等于该门槛全通过 |
| B1 | 完整原壳、图层/选择、独立构建/profile 与只读服务装载副本；同条件成对截图和交互核对 |
| B2 | 复制原编辑/Undo、通信、上传、保存与恢复；保存关闭、主页重开和服务重启恢复；全部原可用功能目录对照通过，新旧不串写 |
| P1a/P2a | 标准导入/稳定语义、原界面编辑、原生保存、固定版本投影/正式发布与重开；元数据撤销/复制保持 |
| P1b/P2b | 完整标准包、恢复上传、有限合并、最终校验、角色与生命周期；原能力和已声明标准能力均保持 |
| P3 | 真实插件规范/授权/上传/提交/修复/回执，断线/重试/撤权可恢复且不伪报成功 |
| P4 | 平台固定修订 PSD/FGUI 导出、持久任务/租约/取消、文件回读与目标验收 |
| P5 | 后续目标回写与更多引擎，单独安排 |

每包复用原测试并调整产品绑定，新增验证覆盖隔离、桥接及真实端到端；不因历史通过数跳过副本验证。B1 可暂禁未接写操作，B2 必须保留原全部实际可用功能，不能只通过图层/编辑/历史关键路径后留空其余功能。已有复制保存链作为标准/GPT 接入基础，不再等待全部原功能验收；不能继续自制预览路线。

## 7. 施工、提交与报告

只在两处独立施工工作树改动；原工作区只读。必要依赖按清单扩充 sparse，不复制整份脏工作树、凭证、数据库、安装依赖或无关 FGUI 实现。当前未提交预览/宿主实验保留并排除正式提交；既有标准会话作为参考，不能强制原编辑器迁就。

用户已授权实施、提交和推送本任务相关改动；按仓库分开提交，保留无关工作，不强制推送。固定来源副本已单独提交，后续继续按私有装配、原生通信/持久化、完整功能验收、标准桥接与插件分批记录。逐包报告实际来源、改动、运行指纹、通过/失败/未验证、证据和提交；静态定位、文件存在、模拟回执或自制 UI 不能冒充功能已用。
